# Week1Labs — StudyBuddy

A student task and reminder app built with React Native, Expo, and Firebase as part of the mobile development labs.

## Features

- Email/password login and sign up
- Add, complete, and delete tasks
- Firestore cloud syncing
- Per-user task isolation
- Motivational quotes

## Built With

- React Native
- Expo
- Firebase Firestore
- Firebase Authentication

## Run

Run `npm install`, then `npx expo start` in this repository.
